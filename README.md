Современный, стильный и высокопроизводительный **многостраничный SPA-сайт** для частной стоматологической клиники. Проект разработан с использованием самого актуального стека технологий, обеспечивая мгновенную навигацию без перезагрузок страниц, адаптивный премиум-дизайн и высокую оптимизацию.

---

## ✨ Основные особенности

- ⚡ **Мгновенный SPA-клиент**: Высокая скорость работы и плавная переадресация между страницами благодаря React Router.
- 🎨 **Современный UI/UX**: Элегантный, минималистичный дизайн с упором на комфорт пользователя и доверие к клинике.
- 📱 **Fully Responsive**: Идеальное отображение на всех типах устройств (от смартфонов до 4K-мониторов).
- 🩺 **Интерактивные сервисы**:
  - Полный каталог услуг с детализацией и ценами.
  - Страницы специалистов с фильтрацией по направлениям и стажу.
  - Удобные формы записи на прием и заявки на обратный звонок.
  - Раздел с отзывами пациентов и фото «до/после».
- ♿ **Доступность и производительность**: Оптимизированная семантика HTML5, чистый код и быстрая загрузка.

---

## 🛠 Технологический стек

- **Framework**: [React 19](https://react.dev/) — использование новейших возможностей библиотеки для максимальной производительности.
- **Language**: [TypeScript](https://www.typescriptlang.org/) — строгая типизация для надежности и удобства разработки.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) — высокоскоростной движок стилизации нового поколения с переменными CSS.
- **Routing**: [React Router](https://reactrouter.com/) — организация многостраничной структуры в формате SPA.
